# 每个新终端加载 Bash 配置

目标：先以交互 Bash 加载目标用户的 `~/.bashrc`，再执行公共初始化和窗口命令。本机、远程、调试和新建 tmux 会话共用脚本构造入口；重连不重复初始化。

实现：保留不读取配置的传输握手，握手后进入真正的交互 Bash。任务使用脚本输入，手动终端使用自定义 rc 文件，在同一 Shell 中保留环境、函数、别名和提示符。通过进程替换传递脚本，避免大脚本超过系统参数长度限制。公共初始化仍遇错停止，手动输入恢复普通交互终端的错误处理。
